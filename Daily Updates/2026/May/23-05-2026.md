##### Building an HTTP server from TCP
###### content:
- Learning a network protocol
- Learning how to stream data from a file to your program.
- Covering TCP (and contrast it with UDP)

HTTP streams:
- Opening a file in golang: `os.Open("filename.txt")`
- Reading from a file f.Read(data):# data is the storage structure for the data that is read. 
- logging an error: `log.Fatal("error message")`
- creating a slice of data: make([]byte, byte_size)
    In Go, IndexByte is an inbuilt function found in the bytes and strings packages. It is used to find the index of the first occurrence of a specific byte within a source.
    snippet: `bytes.indexByte(data, '\n')`
    - converting bytes of data to a string string(data[:n])
